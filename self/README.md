# سلف‌بات حرفه‌ای تلگرام (چندکاربره)

سلف‌بات با قابلیت‌های: ساعت فنسی، ریکت خودکار، تپچی (بنر)، افکت متن، اسپم، اکشن،
**قفل پیوی** (جدید) + **ربات مدیریت چندکاربره** (جدید).

---

## ۱) قفل پیوی 🔒 — حذف دوطرفه خودکار پیام‌ها

وقتی پیوی یک نفر را قفل کنید، **هر پیامی که برایتان بفرستد در کسری از ثانیه برای
هر دو طرف حذف می‌شود** (مثل حذف دستی → «حذف برای همه»؛ فقط خودکار).

### دستورات قفل

| روش | دستور |
|---|---|
| داخل پیوی خود فرد | `قفل پیوی` یا `پیوی قفل` |
| ریپلای روی پیام فرد (گروه/هرجا) | ریپلای + `قفل پیوی` |
| با یوزرنیم | `قفل پیوی @username` |
| با آیدی عددی | `قفل پیوی 123456789` |

### دستورات حذف قفل

| روش | دستور |
|---|---|
| داخل پیوی فرد یا ریپلای | `حذف پیوی قفل` یا `حذف قفل پیوی` |
| با یوزرنیم | `حذف پیوی قفل @username` |
| با آیدی عددی | `حذف قفل پیوی 123456789` |
| با شماره لیست | `حذف قفل پیوی 2` |

### مدیریت لیست

- `لیست قفل پیوی` (یا `لیست پیوی قفل`) → نمایش قفل‌شده‌ها + تعداد پیام‌های حذف‌شده
- `پاکسازی قفل پیوی` → حذف همه قفل‌ها

> پیام تایید دستور در چت طرف بعد از ۵ ثانیه خودکار پاک می‌شود تا ردی باقی نماند.
> در پنل اینلاین (`پنل`) هم بخش «🔒 قفل پیوی» اضافه شده است.

---

## ۲) ربات مدیریت سلف (چندکاربره) 👑

`manager_bot.py` یک ربات مستقل است که برای **چند نفر** سلف اجرا می‌کند.
مدیر اصلی (`ADMIN_ID`) تعیین می‌کند سلف هر کاربر **فعال/غیرفعال** باشد و
**چه مدت** فعال بماند.

### جریان کاربر

1. `/start` در ربات مدیریت
2. **«📱 ساخت اپ و دریافت API»** → آموزش قدم‌به‌قدم ساخت اپ در my.telegram.org →
   ثبت `api_id` و `api_hash`
3. **«🔐 فعال‌سازی سلف»** → ارسال شماره → کد تایید → (رمز دومرحله‌ای اگر دارد) →
   ساخت خودکار:
   - **سشن** با نام یکتا در `sessions/`
   - **`config.json`** اختصاصی در `data/<آیدی کاربر>/`
4. درخواست برای مدیر می‌رود → مدیر مدت اعتبار را انتخاب می‌کند → سلف اجرا می‌شود
5. (اختیاری) **«🤖 توکن ربات پنل»** → برای فعال شدن پنل اینلاین (دستور `پنل`)

### پنل مدیر

- **⏳ درخواست‌های در انتظار** → تایید (با انتخاب مدت: ۱/۷/۳۰/۹۰ روز، نامحدود، دلخواه) یا رد
- **👥 لیست کاربران** → جزئیات هر کاربر: وضعیت، اعتبار، پروسه
- **⏰ تمدید اعتبار** / **🔴 غیرفعال کردن** / **🗑 حذف کاربر** (با حذف سشن و کانفیگ)
- **Watchdog**: پایان اعتبار → توقف خودکار + اطلاع به کاربر و مدیر
- **ری‌استارت خودکار**: اگر سلف کاربر کرش کرد (حداکثر ۵ بار در ساعت)

### اولین کانفیگ برای مدیر

هنگام اولین اجرا، رکورد مدیر ساخته می‌شود و اگر فایل‌های تک‌کاربره‌ی قدیمی
(`config.json` و `user_session.session`) وجود داشته باشند، به عنوان
**کانفیگ و سشن مدیر** به ارث می‌رسند؛ یعنی همان تنظیمات فعلی شما حفظ می‌شود.

## اجرا

### حالت چندکاربره (پیشنهادی)

```bash
cd self
pip install -r requirements.txt
cp .env.example .env   # مقادیر را پر کنید
python manager_bot.py
```

در `.env`:

```
API_ID=...        # اپ مدیر (my.telegram.org)
API_HASH=...
BOT_TOKEN=...     # توکن ربات مدیریت (@BotFather)
ADMIN_ID=...      # آیدی عددی مدیر اصلی
```

> ⚠️ اگر قبلاً `main.py` را جداگانه اجرا می‌کردید، قبل از روشن کردن ربات مدیریت
> آن را متوقف کنید تا سشن مدیر در دو پروسه هم‌زمان استفاده نشود.

### حالت تک‌کاربره (مثل قبل — بدون تغییر)

```bash
cd self
python main.py      # همان .env قبلی: API_ID / API_HASH / PHONE_NUMBER / BOT_TOKEN
```

این حالت دقیقاً مثل قبل کار می‌کند (سازگاری کامل حفظ شده).

## ساختار فایل‌ها

```
self/
├── main.py            # سلف‌بات (قابل اجرا مستقیم یا توسط manager)
├── manager_bot.py     # ربات مدیریت چندکاربره  ⭐ جدید
├── db.py              # دیتابیس کاربران (JSON)  ⭐ جدید
├── pv_lock.py         # ماژول قفل پیوی  ⭐ جدید
├── bot.py             # پنل اینلاین (+ بخش قفل پیوی)
├── panel.py           # متن/دکمه‌های پنل (+ راهنمای قفل پیوی)
├── clock.py / reaction.py / banner.py / effects.py / spam.py / action.py / ...
├── config.json        # کانفیگ تک‌کاربره (در حالت چندکاربره = کانفیگ مدیر)
├── sessions/          # سشن‌ها (gitignore)
├── data/              # دیتابیس + config.json هر کاربر (gitignore)
└── logs/              # لاگ سلف هر کاربر (gitignore)
```

## نحوه‌ی کار main.py در حالت چندکاربره

ربات مدیریت برای هر کاربر یک پروسه‌ی `main.py` با متغیرهای محیطی اختصاصی اجرا می‌کند:

| متغیر | معنی |
|---|---|
| `SELF_API_ID` / `SELF_API_HASH` | API کاربر |
| `SELF_SESSION` | مسیر سشن (مثلاً `sessions/u123`) |
| `SELF_BOT_SESSION` | مسیر سشن ربات پنل کاربر |
| `SELF_CONFIG` | مسیر config.json کاربر |
| `SELF_BOT_TOKEN` | توکن ربات پنل (اختیاری) |
| `SELF_PHONE` | شماره کاربر |

اگر این متغیرها نباشند، از متغیرهای قدیمی (`API_ID` و ...) استفاده می‌شود.
